## 现象

`docs/language-spec.md` 约 216KB 单文件；`docs/spec/` 目录目前只有 AI 工作流文档。
外部报告建议 v1.1 议“拆分或维持现状”。

## 选项

| 方案 | 内容 | 风险 |
| --- | --- | --- |
| A 维持单文件 | 只加目录锚点与“按节阅读”入口 | 体量继续增长；搜索/审阅成本高 |
| B 按层拆 | `spec/lexical.md` / `types.md` / `ownership.md` / `packages.md` + 总索引 | 链接迁移面大；`check-docs` 锚点需全量重跑 |
| C 按特性拆 | 每个 §4.x 一文件，总文件保留索引 | 文件数暴增；跨节约束难表达 |

## 建议

v1.1 先做 **B 的只读评估**：统计各章节被链接次数、锚点引用、生成/门禁依赖；
再决定是否拆。v1-PH-0 不动 spec 结构（冻结期只收 bugfix/重写切片）。

## 验收（若进入 v1.1）

- 拆分前后 `check-docs` 链接数/锚点通过；
- 旧 URL/锚点有重定向或保留兼容节；
- 总索引可定位每个特性；
- 单 PR 回滚。

## 非目标

- 不在 v1-PH-0 / v1.0 冻结期改 spec 结构；
- 不重写 spec 内容（只搬移 + 索引）。
