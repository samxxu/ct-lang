| 模块 | lang / selfhost（绑定点查找与转换） |

| 锚点 | v0.88.3（2026-11-22） |
| 依据 | [REQ 卡评估](../../docs/reviews/2026-11-22-req-node-conversion-protocol-eval.md) |

## 现象

`Vec<int> v = node;` 当前没有绑定点的隐式转换；节点取值只能显式调用。
REQ 提案希望把“节点 → 容器/标量”的转换固定在绑定点，作为 JSON 等动态格式的主体验。

## 期望（v1.1，先 ADR）

1. **只在绑定点转换**：声明初始化 / 赋值 / `out` 实参 / `return`；表达式内绝不转换
   （`node + 1`、`f(node)` 编译错），负例进 `test/ast`。
2. **两档协议**：`as<T>`（宽松，缺省兜底）与 `.to<T>() -> Option<T>`（严格）成对存在；
   **绑定点裸写默认走宽松档**（所有者裁定）；严格档由 `.to<T>()` 与 `decode<T>` 边界承担。
3. **查找规则**：源类型固有方法 + 已 import 的映射 trait；未 import 时给可行动指引。
4. **容量**：SH-109 已在当前 pre 窗口放开固定 512（动态增长、65536 安全阀），本项不再受
   501/512 或 ≤11 约束。
5. **ADR 必写**：查找顺序、歧义、默认档、表达式禁区、与 `--types` 的关系、回滚。

## 非目标

- v1.0 实施；
- 表达式内隐式转换；
- 运行时反射 / 自动派生。

## 验收

- ADR 先过审，再进实现；
- 负例：表达式内转换、未 import 映射、歧义候选；
- 正例：声明/赋值/`out`/`return` 四类绑定点；
- 生成 C 中等价于显式 `as<T>()` 调用（对照组）；
- `--types` 全语料 FP=0；新增语料进 J-6；
- spec 新增节（节锚点，行号禁）。
