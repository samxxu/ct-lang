> **状态：`closed`**（2026-11-20；裁判 EDITOR；1 轮 claim/counter/evidence）。
> **结论：B 胜——现在不受理整体「指针退场」提案；目标保留，方案退回 v2 / REQ，先补五项前置证据。

| J-5 机制自洽 | **B** | 提案自称「机制最小化」，实际新增 `box<T>`、`new`、`ref/out`、切片、`Str` 字面量、函子类型六项；J1 要求「与指针写法产物逐字节一致」，与 box 的 refs 头部、Str 的 16 字节布局、切片的 len 字段直接矛盾 |
| J-6 证据充分性 | **B** | 附件只有设计，没有原型、没有真实语料迁移数据、没有成本量化；按 §7.7 E1–E5，A 未给出可复现的编译/运行证据 |
| J-7 成本/回归 | **B** | 5 个切片 + std Wave 2；语料含字面量的 `.ct` 文件 649 个、`char *` 494 处；v1.1 已有「行为保持 + A strict」承诺，再加这 5 项等于把 v1.1 变成语言 MAJOR |
| J-8 可分期/回滚 | **A（局部）** | S2 复用 PH-70、S4 复用 PH-75、S3 可独立；但 S1/S5 是 ABI/类型层前置，不能单独回滚。分期性成立，不足以支撑「现在整体受理」 |

## 2 为什么不采纳「整体受理」

1. **版本窗口冲突**：v1.0 冻结、v1.1 行为保持，是已发布路线；提案是语言 MAJOR 级变更。
2. **自证判据不可达**：J1 对 box / Str / 切片不可满足；一个自己判据就不闭合的方案不能进施工。
3. **ABI/语法迁移面被低估**：`Str` 非内建、`T[]` 与 `int a[]` 冲突、`ref/out` 已是标识符；
   提案只处理了 `new` 一个关键字。
4. **安全前提缺失**：无借用检查、无环检测、无逃逸限制，却把 box/ref 推成日常默认；
   这不是「零成本」，是把泄漏与悬挂从显式指针转移到隐式句柄。
5. **证据门槛未过**：无原型、无语料、无成本；按 battle 规则只能判 B。

## 3 C 方案（保留目标，不进 v1）

把提案登记为 **v2 语言方向 REQ**（不占 phase、不 bump），先完成五项前置；全部达标后再开 v2 卡：

| ID | 前置 | 可机械验收 |
| --- | --- | --- |
| P-1 | **语料迁移测量**：对 649 个含字面量文件、494 处 `char *`、现有 `T a[]` 用法，给出 box/Str/slice 的逐类改写量与不可自动改写量 | 统计脚本 + 抽样 diff；给出百分比与失败清单 |
| P-2 | **语法/保留字方案**：`new`/`ref`/`out`/`box`/`T[]` 的关键字或上下文规则；对现有标识符零冲突或提供迁移器 | 语料全量 parse 通过；旧代码零改写的正例；冲突负例 |
| P-3 | **`Str` 内建化/ABI 方案**：编译器内建 vs std 类型；字面量类型、`printf`/C 边界转换、`.m.ct` recipe 的 ABI 表 | 设计文档 + 最小 ABI 探针；与 PH-65 strict 边界不冲突 |
| P-4 | **`ref/out` 逃逸规则 + `box` 引用环策略**：不引入借用检查的前提下，如何禁止保存指针/检测环，或明确接受并给出可观测告警 | 逃逸矩阵探针；环泄漏探针与契约文本 |
| P-5 | **原型**：至少 S1（box+new）与 S3（slice）最小原型，跑 J1/J4/J5 的对照语料 | 可编译可运行原型 + 原始输出；未达标即不进入 v2 卡 |

## 4 不采纳的具体项（当前版本）

- 整体受理并按 S1–S5 排入 v1 前；
- J1「与指针写法产物逐字节一致」作为 box/Str/slice 的通用判据；
- `Str` 字面量默认化在 v1 前落地；
- 把 `T[]` 直接定义为切片值类型而不处理既有 `T a[]`；
- 「提案只新增一个关键字」的表述；
- 在无逃逸限制下把 `ref/out` 作为日常参数默认。

## 5 保留并认可的部分

- **问题陈述**：堆单对象、多返回、数组传递、字符串、回调五类日常用途确实仍依赖指针；
- **Vec 句柄模型**：refs/release/借用视图已在 CT 上验证（[Vec.h.ct:29-32](../../lib/std/Vec.h.ct#L29-L32)），
  box 与其同构是合理方向；
- **S4 函子参数类型**与 **S2 `out`** 是提案中面最小、复用最多的两项，可作为 v2 首批候选，
  但仍需 P-2/P-4 前置；
- **零禁止**原则保留：指针/own/defer/errdefer 继续合法，不因本提案被削。
