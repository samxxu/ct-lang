## 争点

PH-88 卡 E88-1 写“发射器函数集重写完成；tag 判别换穷尽 `match`”。PH-87 复核
（§3.3）已确认字面 `match` 在 v0.87.0 的引导链下**不可能**：ct-ast 源码由 L2
引导编译，L2 不实现 PH-84 的 ADT/`match`，ADT 语法会被 L2 原样发射成非法 C。
PH-87 把这条欠账移交 PH-88，并要求 PH-88 在开工前把**承接目标写死**，否则
欠账会静默丢失。

本 battle 要判的是：PH-88 能否以“发射器按 kind 切片 + 自举不动点参数化 +
探针 + 语言级判据”交付 E88-1，并把字面 `match` 的承接目标与范围写死。

## 技术前提（本机原始输出）

```console
$ cat /tmp/p88dev/ce/adt.ct
enum NodeKind {
    AdtCtor(int n),
    Var(int n),
}

int main(void) { NodeKind k = NodeKind.Var(7); return 0; }
$ /tmp/p88dev/l2 /tmp/p88dev/ce/adt.ct -o /tmp/p88dev/ce/adt.c
L2 rc=0
$ head -6 /tmp/p88dev/ce/adt.c
/* Generated by ct v0.87.0 … */
enum NodeKind {
    AdtCtor(int n),
    Var(int n),
}
$ cc -std=c99 /tmp/p88dev/ce/adt.c -o /tmp/p88dev/ce/adt.bin
/tmp/p88dev/ce/adt.c:4:12: error: expected '= constant-expression' or end of enumerator definition
    4 |     AdtCtor(int n),
cc rc=1
$ CT_C_BOUNDARY=allow /tmp/p88dev/ct-ast-sliced /tmp/p88dev/ce/adt.ct -o /tmp/p88dev/ce/adt_ct.c

```

同一份源码 ct-ast 能编，L2 编不了；`L1`/`L2` 中 `N_ADTCTOR|Type.Variant|N_MATCH`
命中 0（见 [p87 证据](../../test/probes/p87_l2_adt_evidence.txt)）。这不是实现
选择，是 v0.88.0 引导链的前置条件。

## 候选

| # | 方案 | 代价 |
| --- | --- | --- |
| A | **PH-88 只做可验证切片**：五个判别函数按 kind 切成 76 个 free function，判别式只读一次；fixpoint 轮数参数化（日常 2 / tag 前 3）；`p88_emit` 清单 + 变异自测 + 66 语料逐字节。字面 `match` 承接目标写死为 **v1.0 seed cutover（`v1-PH-0`）**，范围含 76 切片 + `expr_ctype`/`maybe_box`/`chk_type` | E88-1 只能记“部分通过（切片完成，字面替换未做）”；需 REVIEW 追签；v1.0 出口判据必须接住 |
| B | PH-88 内显式新增“换 seed”任务，先换 seed 再写 `match` | 会提前执行 v1.0 §1.2 的 seed cutover（L1/L2 退役、构建链重写、golden/CI 换基），超出本卡非目标与工期；且 `v1-PH-0` 的 AST-only 收口尚未开始，等于把 v1.0 塞进 PH-88 |
| C | 只在夹具/文档里写 `match`，声称“可机械替换”即算通过 | 编译器源码没变，是假绿；E88-1 的“重写”落空 |

## 建议判据（供裁判引用）

| # | 判据 | 通过条件 |
| --- | --- | --- |
| J1 | L2 前置 | ADT 源码经 L2 发射为非法 C 且 ct-ast 可编（上节原始输出） |
| J2 | 切片可验证 | `p88_emit` 76 切片清单、每判别式 `nodes[n].kind` 恰 1 次、删一支必红 |
| J3 | 等价 | 66 语料逐字节；345 诊断逐字；自举不动点 2/3 轮 |
| J4 | 承接写死 | 卡的退出判据/承接节与 v1 路线同一条：`v1-PH-0` seed cutover；范围含 `expr_ctype`/`maybe_box`/`chk_type` |
| J5 | 不假绿 | 不把字面 `match` 记成通过；E88-1 记“部分通过 + 承接” |

## 待判

1. 选 A 是否成立；若成立，E88-1 的“字面 `match`”是否按 J4 记为 **v1-PH-0 的入口判据**；
2. 承接范围是否按 PH-87 复核 §3.3 第 2 条，包含 `expr_ctype`、`maybe_box`、`chk_type`；
3. 本判决需非作者席位追签（DEV 不自签，0.7/T-8）。
