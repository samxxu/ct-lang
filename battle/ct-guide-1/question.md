# battle/ct-guide-1 — 《给 C 程序员的 CT 内存指引》哪些断言必须按 v0.83.x 实现改写

## 争点

指引的教学骨架（心智地图、String/Str 判据、逃生层、残余风险）成立；争点是**事实层**：

- 指引按“目标形态”写的地方，是否已经越过 v0.83.x 的实际实现；
- 绝对化措辞（“永远”“无”“不禁止任何东西”“只出现在”）是否应改为带条件的表述；
- 示例 API 是否真实存在、参数语义是否正确。

不讨论文风、章节顺序、篇幅；只裁定“必须改 / 可保留 / 待实测”。
