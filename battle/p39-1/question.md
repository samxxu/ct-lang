## 逐条判据（J-1…J-5）

| ID | 判据 | 通过方式 |
| --- | --- | --- |
| J-1 | **意图一致**：`.abi.h` 的导出集合 = 作者明确要导出的集合；用三个夹具（纯 C 兼容库 / 含泛型 `pub` helper 的库 / 含 trait 类型 `pub` 方法的库）分别构建，方案能否只导出作者要的、且不把其余判死 | 夹具 + 命令输出 |
| J-2 | **既有代码零语法改动**：仓库内 `lib/std/**/*.h.ct`、`test/modules/**/*.h.ct` 不改一行即可构成 `--lib` 库；统计其中「非 C 兼容 `pub` 函数」的数量与位置 | `grep` + 解析结果 |
| J-3 | **语言面最小**：不新增关键字 / 语法（`AGENTS.md` 第 7 节：新增语法需用户批准）；若 B 必须新增语法，须给出用户批准证据，否则 J-3 不通过 | 方案文本 + 锚点 |
| J-4 | **实现成本**：≤2 文件 / ≤80 行；不改变 G1/G3/G4 的既有判据 | 改动清单与行数估算 |
| J-5 | **可诊断**：被拒绝的签名必须给出 `file:line:col` 与原因，不得静默丢弃 | 负例输出 |
