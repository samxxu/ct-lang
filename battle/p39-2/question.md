## 逐条判据（J-1…J-5）

| ID | 判据 | 通过方式 |
| --- | --- | --- |
| J-1 | **ABI 洁净**：`nm -g --defined-only` 是否只剩导出函数；若 B 能做到而 A 不能，J-1 归 B | 命令输出 |
| J-2 | **平台可移植**：同一套命令在 macOS + Linux 的默认工具链可用，不新增第三方依赖、不引入构建系统 | `command -v` + 两平台命令 |
| J-3 | **静态链接语义不变**：本地化后消费者仍能链接导出函数，vtable 的跨单元引用仍成立；`check-ast` 全量语料零回归 | 链接/运行夹具 + 门禁 |
| J-4 | **成本**：≤2 个文件、≤120 行；平台分支数、回退步骤、失败模式（工具缺失时怎么办） | 改动清单与估算 |
| J-5 | **可复现**：每条证据有命令、原始输出、环境；工具缺失时明确写 `skip` 而非默绿 | `verify.json` |
