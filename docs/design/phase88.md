## 1 需求与边界

### 1.1 重写内容

- 发射器函数集切片重写：`switch`/`if` 链中的 tag 判别换穷尽 `match`；
- 手写可增长 buffer / 格式化拼接按适用性改用 `String`；
- 错误路径 `?`/errdefer；不改发射格式与命名契约。

### 1.2 自举回环（D-017/D8）

- 复用 `check-ast` 的 §9.6 不动点段，**轮数参数化**：
  - 日常/每切片 2 轮；
  - v1.0 tag 前 3 轮；
- 同一套比对逻辑，零代码分叉；不新建脚本。

### 1.3 等价判据（D-017 A1）

- 测试语料发射产物逐字节不变；
- 编译器自身实现的发射 C 允许差异；验收 = 自举不动点 + ASan + 行为测试；
- 期望文件集合基线 + 旧→新映射保持有效（M0 后若变化需更新）。
