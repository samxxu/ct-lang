## 3 sharp edge（重写时踩到/确认的坑）

| # | 坑 | 证据/后果 | PH-86 的处置 |
| --- | --- | --- | --- |
| 1 | 方法只能经 `LexOps` 的 `self->` 调用；自由函数要 `struct Lexer *`，签名会进 `.h`，而头文件不带 `#include` | 分成方法是最小风险形状；`lex_ident_start` 只收 `int` 才能做自由谓词 | 保持“方法 + 原始类型谓词” |
| 2 | 分支体依赖 `next` 的局部 `c` 与 `return;`；搬进方法后要么传参、要么重读 `src[pos]` | `number` 重读 `src[pos]` 与 `quoted/punct` 传参，二者等价仅因“进入分支后 `pos` 未变” | 重写时把 `c` 当参数显式传入，禁止重读 |
| 3 | `...` / `..` / `.5` 的顺序：`...` 必须先于 `..`，`..` 必须先于 `.5`；`<<=`/`>>=` 先于 `<<`/`>>`；`=>` 先于 `==`/`>=` | `punct` 141 行里全是顺序敏感的链 | 表驱动时必须保序，且加 3 个负例（`1...5`、`a..b`、`.5`） |
| 4 | token 文本是 `char toktext[160]` 定长缓冲，另有 3 个独立截断标志（`toktrunc`、`toksuffix`、`tokfloat`） | `Str` 视图迁移（B4 目标）会改 `Lexer` 的公开字段，波及 Parser/Expr/Stmt 的全部 `toktext` 读取 | 单列任务，不属于“等价重写” |
| 5 | 词法器**没有错误通道**：非法输入由解析器报，`toktrunc` 是标志位 | `?` 在词法器上无处可挂 | PH-86 不要为用 `?` 而造错误通道 |
| 6 | `num_accumulate` 饱和到 `LONG_MAX`（UBSan 护栏，SH-86 后续） | 重写若改溢出策略会改变 `range_bound_value` 的报错位置 | 保留饱和，加 UBSan 用例 |
| 7 | `bol`/`lstart` 的 LANG-16 不变量（块注释跨行后列号重置） | 提取注释循环时最容易丢 | 保留 `lstart = pos + 1` 的赋值点，加跨行块注释列号负例 |
| 8 | 宏不跨单元：`MAX_TEXT` = 160、`T_EOF..T_PP` = 0..5 在每个单元重复定义 | 新单元必须抄同一组常量；漂移会让 token 编号错位 | 保持字面量并在 inventory 里登记（§2.2） |
| 9 | `struct Lexer` 的字段数逼近 `MAX_FIELDS`(64)？当前 15 个，trait `use` 列表加方法不影响字段 | 加方法只改 vtable，不改结构体布局 | 允许；但方法数计入 `MAX_METHODS`(64)，`LexOps` 6 个远未触顶 |
| 10 | `#line`/诊断位置：词法器只设置 `tokline/tokstart`，不打印 | 重写若把行号维护移到辅助方法外，列号会偏 | 行号/列号只由 `next` 维护，辅助方法只读 |

## 4 结论（诚实口径）

| 判据 | 结果 |
| --- | --- |
| 结构等价（拆分、逐字节语料、不动点、零告警） | **通过**（§1/§2 原始输出） |
| 整子系统“新语法等价重写”（`Str` 视图 / `?` / `defer` / `match`） | **不通过（未覆盖）**：本切片没有迁移 token 文本，也没有错误通道可挂 `?`；`match` 在这里无 ADT 判别对象 |
| 门的含义（卡 §1.3 / R85-1） | **作为“PH-86 可以一次整体重写”的门：不通过。** 按 R85-1 退化为“按 inventory 逐项替换”：先 punct（141 行）与 number（83 行）两个方法级切片，再把 `Str` token 视图作为独立任务（B4），最后才谈词法器整体重写 |

- 已证明的部分：把 309 行的 `next` 拆成 5 个 token 类方法，语料逐字节不变、
  自举不动点成立、零告警、构建时间不变。这是 PH-86 的**结构**前提。
- 未证明的部分：`Str` 视图对解析器消费者的连锁影响、`?`/`errdefer` 在词法器上
  的收益（无错误通道/无资源）。**不得**把本切片记作“整子系统重写通过”。
- 建议时序：PH-86 卡按“punct → number → quoted/pp_line → Str 视图”四段拆；
  PH-87/88 的门不变（测试语料逐字节不变）。
