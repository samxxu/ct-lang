# Phase 51 — 指针接收者 `.` 调用的发射缺陷（链式前置）

> **状态：完成（2026-11-15；v0.51.0；S1–S5 全绿；选型 A）**
> **归属**：本仓库维护规格与判据；实现由外部 harness 交付（[手册](phase46-52-handoff.md)）。
> **基线**：本卡最后一次提交。
> **规模**：50–120 行（选型 A）/ 100–250 行（选型 B）。
> **版本**：`v0.51.0`（若采纳 U-4 A）。

## 0 一句话目标

让「`.` 作用于指针接收者」不再把 `S**` 传给方法：要么硬错要求 `->`（A），要么自动解引用发 `S_f(p)`（B）。

## 1 本卡做 / 本卡不做

| 做 | 做不做 |
| --- | --- |
| 修 `.` + 指针接收者的发射/诊断；`->` 路径零改动 | 不做「方法结果作接收者」（SH-73，独立缺陷） |
| 泛型实例（`void *self`）与非泛型实例都覆盖 | 不做自动解引用链（`p.q.f()`） |
| 生成 C 实参形态断言（`p` 而非 `&p`） | 不改 `self` 在方法体内的绑定 |
| S0 统计既有用量，决定 A/B | 不扩 `[]` 协议（PH-52 明确不做指针接收者） |

## 2 前置依赖

无。必须先于 PH-52 的连写验收；不阻塞 46–50。

| 形态 | 生成实参 | `cc` | 运行 |
| --- | --- | --- | --- |
| 非泛型 `struct S *p; p.f();` | `S_f(&p)` | `incompatible pointer types` warning | 错值 |
| 泛型 `Vec<int> *p; p.push(7);` | `Vec_int_push(&p, 7)`（`void *self`） | **零告警** | rc=139 |

代码锚点（F14）：接收者判定 `Expr.h.ct:4352`、`:4232-4245`；发射 `Emitter.h.ct:5022-5024`、
`N_MCALL` 入口 `:4863`。

## 4 修法方向

| 选型 | 规则 | 改动 |
| --- | --- | --- |
| **A（默认）** | 指针接收者 + `.` → 解析期硬错 L51-1，要求 `->` | `Expr.h.ct:4352` 的接收者分类加硬错；不碰发射 |
| **B（仅当 S0 计数 > 0 且用户签字）** | 自动解引用，发射 `S_f(p)` | `Emitter.h.ct:5022-5024` 按接收者是否指针选 `p` / `&p`；重生成 golden |
| 共用 | 判定只按「接收者静态类型是否指针」，不看结果类型 | `Expr.h.ct:4232-4245` |

**D51-1（冻结）**：默认 A。B 必须用户签字（U 清单外，属执行期变更）。
