## 1 需求与边界

### 1.1 重写内容

- 解析器：节点构造、错误路径（`?`/errdefer）、表达式/语句分发；
- 检查器：`node->kind` 的 tag 判别换成**穷尽 `match`**（PH-84 能力）；
- 函数集切片：每切片列函数清单，行为等价；
- A checker dogfood：用 PH-85 的机制对编译器自身跑 `warn` 档，记录 FP/崩溃。

### 1.2 等价判据（D-017 A1）

- 测试语料发射产物逐字节不变；
- 编译器自身实现的发射 C 允许差异；验收 = 自举不动点 + ASan + 行为测试；
- **诊断文本不变**（错误/警告文案与位置）。
