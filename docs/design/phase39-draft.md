## 1 目标与边界

### 1.1 一句话

给 `ct build` 增加 **`--lib`**：产出 `lib<name>.a` + `<name>.abi.h`，只导出 `.h.ct` 里 `pub` 且 C 兼容的函数，并用 visibility 把内部符号藏住。

### 1.2 三项

| 编号 | 内容 | 今天 |
| --- | --- | --- |
| O1 | `ct build --lib` 产出 `.a`、`.o`、`.abi.h`；C 工程可直接 `#include` 并链接 | 只有可执行文件与分单元 `.c`；无 `.a`/`.o` |
| O2 | 导出清单 = `.h.ct` 的 `pub` 函数；trait/接口值/泛型/`Vec`/`Map` 类型出现在导出签名里 → 硬错 | 无导出面概念 |
| O3 | 导出函数带 `visibility("default")`；impl 方法与 vtable 保持 `static`；`-fvisibility=hidden` 编译 | impl 符号今天已是 `static`（实测 `nm`） |

### 1.3 非目标

- 不做 Windows/MSVC、`.dll`/`.lib`；v1 只覆盖 macOS/Linux 的 `cc` + `ar`。
- 不做 ABI 版本协商运行时；只在 `.abi.h` 里放版本宏与导出清单。
- 不做 C++ 头、不做 `extern "C"` 块（CT 没有重载，函数名本来就是 C 名）。
- 不改既有 `ct build`（可执行文件）与模块 `.h` 的「只放类型」契约（D39-1）。
- 不做泛型函数的 ABI 导出（P34 的 `pub` 泛型若需要导出，另立卡）。

### 1.4 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D39-1 | ABI 头是**独立产物** `<name>.abi.h`，模块 `.h` 仍只放类型 | 不违反 Phase 34 的 D34-2 硬边界 |
| D39-2 | 只导出 `.h.ct` 中 `pub` 且 C 兼容的函数；其余硬错 | 导出面必须可预测；trait/vtable 不得进公共头 |
| D39-3 | 导出函数加 `visibility("default")`，其余 `-fvisibility=hidden` | impl 符号已是 `static`；再藏住非导出全局，避免 ABI 漂移 |
| D39-4 | `ar rcsD`（可用时）生成确定性归档 | 两次构建的成员顺序与时间戳稳定；不可用时在文档登记 |
| D39-5 | 导出清单写进 `<name>.abi.h` 的注释与 `nm` 门禁双保险 | 头文件与产物必须一致，防手改 |
| D39-6 | 依赖 P34 的 `pub` 泛型；本相只导出非泛型 `pub` | 泛型导出需要显式实例化清单，独立轴 |

## 3 语义与落码

### 3.1 导出规则

一个函数可导出，当且仅当：

1. 声明在 `.h.ct` 单元，且带 `pub`；
2. 返回类型与参数类型都是 C 兼容的：内建标量、指针、函数指针、具名 `struct`（按值或指针）、数组参数（decay）；
3. 签名里没有 trait/接口值（`*_iface`）、没有泛型参数、没有 `Vec`/`Map`、没有 `own`（所有权不能跨 ABI 边界隐式转移）。

违反 2/3 报 L39-1，位置在声明行；不写任何产物。

### 3.2 产物

```text
libagent.a          # ar rcsD
agent.abi.h         # 版本宏 + 导出原型 + 不透明 struct 前置声明
.ctbuild/*.o        # 中间对象，沿用既有缓存目录
```

`agent.abi.h` 示例：

```c
/* generated by ct build --lib; do not edit */
#define AGENT_ABI_VERSION 1
struct agent_ctx;                       /* opaque */
int agent_init(struct agent_ctx **out);
int agent_step(struct agent_ctx *ctx, const char *input, char **reply);
void agent_free(struct agent_ctx *ctx);
```

- 只出现导出函数与不透明前置声明；不出现 `_iface`、`_vtbl`、`Vec_*`、`Map_*`。
- 导出函数原型由 `.h.ct` 的 `pub` 声明直接生成；定义仍由属主单元发射。
- 头文件顶部写 `AGENT_ABI_VERSION`，包版本由 ct-pkg 自己管；本相不做版本协商。

### 3.3 可见性与链接

- 编译中间对象时加 `-fvisibility=hidden`；导出函数在生成的定义与原型上加 `__attribute__((visibility("default")))`。
- impl 方法与 vtable 已是 `static`（§2.2），不需要额外处理；E39-2 用 `nm -g` 锁住。
- `ar` 只归档本相产出的对象；不把用户手写的 `.o` 混进去。

### 3.4 诊断

| 编号 | 触发 | 文案要点 |
| --- | --- | --- |
| L39-1 | 导出签名含 trait/接口值/泛型/`Vec`/`Map`/`own` | `'<name>' cannot be exported: <reason>` |
| L39-2 | `--lib` 但根单元不是 `.h.ct`，或没有任何 `pub` 函数 | `no exported functions in '<unit>'` |
| L39-3 | 导出函数与 C 关键字/库符号重名 | `exported name '<n>' collides with a C symbol`（可选，S0 评估） |

三条都在 `ct build` 内硬错，不写 `.a`/`.abi.h`。
