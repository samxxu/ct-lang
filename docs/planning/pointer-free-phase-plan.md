## 0. 原则

1. 一轮一张卡；J-6 证据通过后才开第一张正式卡。
2. `S2` 与 `S3` 无技术依赖，可并行准备；按单卡纪律先开 S2。
3. `S5` 依赖 S3 与句柄协议；`S1` 依赖 S5 的句柄协议，放最后。
4. `S4` 函子延后到 v1.1+ Wave 2，不占 v0 phase。
5. 每个 phase 独立红/绿、独立回滚；S5 分 S5a/S5b，不能整体单回滚。
6. **并行准备、串行施工**：同一时刻只有一张卡处于施工态；其余卡可开卡做证据/设计/夹具，
   但施工入口未过前不得落实现代码。

## 4. 每相验收要点

### PH-78 S2 `ref` / `out`

- `ref`/`out` 上下文关键字，仅形参表生效；
- 签名发射 `T *`，函数体内 `(*name)`，调用点自动 `&`；
- 调用点 lvalue 白名单：变量、字段、`*p`、数组/切片/Vec/Map 元素；字面量/表达式/调用结果/cast 硬错；
- `out` 调用方初始化：trivial 可未初始化；owning 必须已初始化；借用可未初始化；
- `out` 每条退出路径赋值：L1（顺序 + if/else 精确；循环/switch/goto 保守），`ct build` 默认硬错；
- 类型匹配负例；ASan 无泄漏/悬挂。

### PH-79 S3 切片

- `T[]` 唯一切片拼写；`T a[]` 仅无初始化器/形参废弃；`T a[] = {...}` 保留为推断长度数组；
- 切片 place：`s[i]` 读/写/借用作用于底层；越界 trap；`get` 软访问；
- `T[]` 可写、`const T[]` 只读；`String`/`U16String` 不可写；
- 四位置白名单：字段/全局/接口/box/Option/Result/容器/数组元素/泛型实参/闭包捕获硬错；
- 返回局部数组/局部 owning 视图的 lint。

### PH-80 S5 `String` / `Str`

- `String`/`Str` UTF-8；`U16String`/`U16Str` UTF-16，只走工厂；
- `String` 字面量 L1 immortal；`String` 不可变，内容变化返回新值；
- `.data` 只读、不保证 NUL；`cstr()` 是 C 边界出口；
- UTF-8 用户接口码点下标，`byte_*` 字节级；`String[i]` 单码点只读 `Str`；
- U16 核心 JS 方法集（snake_case）；`match`/locale/normalize 走包 + shim；
- S5a 内建层 + 旧 `Str` 限定名并存；S5b 删旧 + std/消费者迁移 + 文档三处同步。

### PH-81 S1 `box<T>` + `new`（✅ v0.81.0）

- `box<T>` 共用 refs 头与静态 release；借用视图/失效检测复用 Vec；
- `new` 完全关键字；只接受具名 struct；`new String`/数组/容器硬错；
- 引用环作者责任；`--debug-leaks` 只报未配对计数；
- 旧 golden 不变；`new` 与 box 同退。

### PH-82 泄漏防护（✅ v0.82.0）

- `ct.pkg` 窄键 `leaks = warn|error`：error 升级现有 leak 诊断与直接环告警，build/compile 失败；
- `box<X>` 字段直接环（限深 3、同环去重、`ct check` 报被抑制点）；
- `/* ct: allow-cycle */` 必须与 struct 同行；树模式见 patterns §5；
- 非目标：运行期环检测、GC/weak、容器/泛型/typedef 间接环；`--debug-leaks` 契约不变。

## 6. 不做什么

- 本计划不代替 phase 卡；卡面另立且保持「规划中」；不改源码、不 bump；
- 不把 S4 函子塞进 v0；
- 不把 `match`/locale/normalize 塞进编译器；
- 不承诺运行期环检测/全量借用检查/线程安全类型系统；
- 不用跨过程分析替代 J-4a/J-4b 的契约。
