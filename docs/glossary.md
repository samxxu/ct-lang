# CT 术语表 / CT Glossary

> 中文
>
> 本表是 `ct` 项目**命名与措辞的唯一对照表**：统一项目名、语言构造、编译器内部符号、测试与阶段用语。
> 与代码或规范冲突时，**以代码和 [language-spec](language-spec.md) 为准**（同 [AGENTS.md](../AGENTS.md) §5）。
> 术语在文档/提交信息/注释中首次出现时，优先使用本表的规范叫法。

## 中文

### 0. 命名硬约定（刻意不统一，不要"修正"）

| 规范术语 | 代码/CLI 形式 | 说明 |
| --- | --- | --- |
| ct（CT = *C with Traits*） | `ct`，源文件后缀 `.ct` | 语言/项目名 |
| ctc | `ctc` | L0 种子二进制名 / `ct` 的**兼容别名** |
| ct（单入口） | `ct` | 已定形态：单入口 `ct`，`ctc` 保留为兼容别名；**7.1–7.3 已落地**（二进制名为 `ct` 即可用 `ct …`——10.7 起该二进制由 ct-ast 提供；安装形态 `ct` + `ln -s ct ctc`；banner 已改为 `Generated by ct …`） |
| ct-lang | 仓库名 `ct-lang` | **仅是 GitHub 仓库名**，不是语言/命令/后缀 |

> 禁止把 `ct` / `ctc` / `.ct` 写成 `ct-lang` / `ctlang` / `.ctlang`（AGENTS §7）。

### 1. 语言构造

| 术语 | 代码形式 | 说明 |
| --- | --- | --- |
| 特征（trait） | `trait T { void m(); };` | 一组方法签名；派生虚表类型 `<T>_vtbl` |
| 结构体（struct） | `struct S { … } use T;` | 数据字段 + `use` 子句 |
| 实现块（impl） | `impl T for S { … }` | 把 trait 的方法绑定到具体 struct |
| use 子句（use-clause） | `} use T, U;` | struct 声明它实现哪些 trait |
| self | `self`、`self->m()` | 方法体内指代自身；生成时展开为 `_self` |
| 命名空间（namespace） | `namespace A::B;` | 文件级声明；符号加 `A_B_` 前缀。块式书写 `namespace A::B { … }` 会被拒绝（`a namespace is file-scoped`）。**已随 Phase 0.3 移出 L0，现由自举编译器 `selfhost/` 用 CT 重做** |
| 命名空间路径 | `A::B`、`A::B::Name` | `::` 分隔各段；访问成员/方法用末尾 `.` |
| 导入（import） | `import A::B;` | 编译单元依赖声明（`ct build`）。**已随 Phase 0.3 移出 L0，现由自举编译器 `selfhost/` 用 CT 重做** |
| 导出（pub） | `pub trait` / `pub struct` / `pub int f(…);` | 多文件模式下符号进 `.h`；前缀本身被剥离 |
| 私有（static） | `static` | 支持的可见性；符号只进 `.c` |
| 析构特征 Drop | `use Drop`、`impl Drop for S { … }` | **保留名**内置 trait；惰性生成释放函数 |
| 释放（delete） | `delete p;` | 对指针展开为 `free`；`use Drop` 时先递归 `drop()` |
| 自动释放（AutoDrop） | `own T *p = malloc(…);` | 作用域出口 / 每个 `return` 前自动 `drop()` + `free()` + 置空（Phase 5；仅 CT 线，L0 不识别） |
| 借用（borrow） | `borrow T *p = …;` / 参数 `borrow T *r` | 借来的指针：作用域出口 / 每个 `return` 之前注入 `handback()` + 置空（无位置要求），**不** `free`；禁 `delete`、禁重赋值、禁存入更长寿变量（Phase 5 续；仅 ct-ast，见 [language-spec](language-spec.md) §4.40） |
| 归还特征 Handback | `use Handback`、`impl Handback for S { … }` | **内置 trait**，照 `Drop` 无 vptr / 无 vtable；`borrow` 的出口调用它（仅 ct-ast） |
| 映射（map） | `map trait T for instance x { m() → CALL; }` | 把 trait 方法映射到某个**已声明的全局实例**上的调用；**Phase 11 已在 ct-ast 落地**（11.1 解析 + 实例级包装 / vtable + `maps` JSON，11.2 接入派发，11.3 加固），L0 / L2 不认识，见 [language-spec](language-spec.md) §4.10 |
| 映射单元（mapping unit） | `lib/lib.m.ct` | 只承载 prologue（`#include` / `#define`）、`pub trait` 与 `map` 的编译期单元；**不产任何产物**，只能被 import（第三十八批，仅 ct-ast） |
| 静态 trait（static trait） | `.m.ct` 里的 `pub trait T { …; }` | 无 `_iface` / `_vtbl` / vtable；不能 `impl`、`use`、作类型、装箱，也不能带默认体 |
| 命名空间静态调用 | `libc::Env.get("HOME")` | 静态 trait 的限定调用，直接展开成 recipe 的 C 调用（无 `self`） |
| 类型宿主（type host） | `map trait CStr for type char * { … }` | 接收者由调用点表达式的静态类型决定（数组先 decay）；`a.toInt()` → `atoi((a))` |
| recipe | `-> memset(s, value, count)` | `->` 右侧的 C 调用模板；绑定参数按出现点替换，`&p` 用 C99 compound literal，未求值参数加 `(void)(…)` 前缀 |
| prologue | `.m.ct` 里的 `#include` / `#define` | 按整行去重展开进消费者 `.c` 顶部；消费者 `.h` 不含它 |
| 伴随 C shim（sibling shim） | `posix/socket.shim.h`（+ 可选 `socket.shim.c`） | 与 `<base>.m.ct` 同目录同名的 C 适配层：shim 头自动被消费者 `.c` include、其目录进 `cc` 行的 `-I`，shim 源直接进 `cc` 行；承接宏 / 全局量 / 转换 / 变参 / 回调（第三十九批，仅 ct-ast） |
| 方言（dialect） | `//@ct-dialect: <名字>` + `//@` DSL 行 | 写在注释里的领域专用语法；`ctc` **零感知**，由**仓库外**的展开器脚本转成纯 CT 后再编译（Phase 6.6；见 [design/dialect.md](history/design/dialect.md)） |
| 方言插件（dialect plugin） | `ct-dialects/<名字>.sh`（`/` 换 `-`；亦接受同名其他后缀，如 `.py`） | 展开器的实现脚本，作者语言自选（bash / Python / awk / PHP…）；门禁按插件自身的 shebang 执行（有执行位直接执行，否则用 shebang 解释器，无 shebang 才退回 POSIX `sh`）；仓库内只允许作**演示 / 测试**（`examples/**`、`test/**`），**不得**进入编译器构建（AGENTS §2） |
| 接口值（interface value / iface） | `struct <T>_iface`、`T x = p;` | 胖指针：`void *self` + `struct <T>_vtbl *vt` |
| 虚表（vtable） | `struct <Trait>_vtbl` | 函数指针表 |
| 虚表指针（vptr） | `__<trait>_vptr` | struct 内字段，指向其 vtable |
| 装箱（boxing） | `Greeter g = p;` | 把 struct 变量/指针转成接口值 |
| 派发（dispatch） | `p.m()` → `p.__<t>_vptr->m(&p)` | 运行时经 vtable 调用 |
| 接收者（receiver） | `p.m()` 中的 `p` | 方法调用的主体 |
| 限定引用（qualified reference） | `A::B::S` | 跨命名空间按名引用类型 |
| 顶层（top level） | 无 `namespace` 的代码 | 不加前缀，产物与 Phase 0 逐字节相同 |
| 闭包（closure） | `int (*f)(int) = (int x) => x + n;` | 非逃逸栈闭包：`=>` 字面量按值捕获外层局部，表面类型是函数指针声明；只在声明作用域内存活，逃逸是硬错（Phase 21） |
| 跳板（trampoline） | `__ct_cl_tramp_<N>(void *self, …)` | 每个闭包字面量生成一个 `static` 函数；先从环境结构体取回捕获值，再执行闭包体 |
| 环境（env） | `struct __ct_cl_env_<N>`、`__ct_cl_env_v_<N>` | 栈上的捕获结构体，作为 `(fn, env)` 参数对的第一个实参传入；与跳板共用一个 `<N>`，**不分配堆内存、不进 vtable** |
| 计数循环（loop） | `loop(3) { … }` | 展开为 `for (int i = 0, __ct_loop_n_K = (3); i < __ct_loop_n_K; i++)` 的语法糖；计数只求值一次，隐式计数器是 `int i`；`loop` 是**上下文关键字**，只在语句位置紧跟 `(` 时生效（Phase 22，仅 ct-ast，见 [language-spec](language-spec.md) §4.45） |
| 数组遍历（foreach） | `foreach (xs) { … item … }` | 在一维数组上迭代，隐式绑定 `item` 为当前元素的值拷贝；展开为 `{ int __ct_foreach_n_K = (int)(sizeof(xs) / sizeof((xs)[0])); for (int __ct_foreach_i_K = 0; …) { <T> item = xs[__ct_foreach_i_K]; (void)item; … } }`，长度只读一次；`foreach` 是**上下文关键字**；只收一维数组变量，其余形态硬错（Phase 27，仅 ct-ast，见 [language-spec](language-spec.md) §4.49） |
| 接收者语境块（into） | `cfg into { .port = 8080; }` | 接收者只求值一次并提升为 `__ct_recvN`；块内 `.name` 是接收者的字段/方法、`$` 是接收者本身；语句形态与三个值位置（声明初始化器 / 赋值右值 / `return`）；`into` 是**上下文关键字**（Phase 30，仅 ct-ast，见 [language-spec](language-spec.md) §4.52） |
| 区间循环（loop range） | `loop(2..5) { … }` | 展开为 `for (int __ct_loop_n_K, __ct_loop_hi_K, i = ((__ct_loop_n_K = (2)), (__ct_loop_hi_K = (5)), __ct_loop_n_K); i < __ct_loop_hi_K; i++)` 的语法糖，半开区间 `[a, b)`；两边界各求值一次、先左后右（由 `i` 初始化器里的逗号运算符定序，C99 §6.5.17）；`loop(0..b)` 等同 `loop(b)`；指针/数组/结构体/函数指针作边界是硬错误（Phase 23，仅 ct-ast，见 [language-spec](language-spec.md) §4.46） |
| 位置式初始化 | `Person p = { "Tom" };` | 按字段顺序 |
| 指定初始化 | `Person p = { .name = "Tom" };` | 按字段名 |
| 空初始化式 | `Person p = {};` | 只写 vptr |
| 抽象方法（abstract method） | `trait T { void m(); };` | 只有签名、没有方法体；采纳处**必须**实现（缺失报错，见 SH-8） |
| 默认方法（default method） | `trait T { int m() { … } }` | 签名后带方法体；采纳处可继承，也可在 `impl` 里覆盖。每 (struct, trait) 各展开一份，不是共享函数（第三十六批） |
| 方法覆盖（override） | impl 里写同名方法 | impl 显式方法优先于默认方法 |
| 直接绑定（direct binding） | `map … { m(buf, len) -> real_put; }` | 裸函数名 → vtable 槽直接指向该 C 函数，**不生成包装函数**；被绑函数首参须为 `void *` |
| 包装函数（wrapper） | `<实例>_<Trait>_<方法>` | `-> f(args)` 形态生成的转发函数；首参 `void *self`，体内 `(void)self;` 后原样调用 |
| 函数指针（function pointer） | `int (*p)(int)`、`p(x)`、`(*p)(x)` | 可作参数 / 字段 / 全局 / 局部；赋值可写 `p = f` 或 `p = &f`；不支持 typedef、不支持返回函数指针 |
| 外部声明（extern） | `extern int lib_flag;` | **只声明不定义**：进 `.h`，`.c` 不发射定义；不能带初始化式、不能是函数 |
| 导出全局（pub global） | `pub int g_counter = 5;` | `.h` 出 `extern`，定义单元 `.c` 出定义；跨单元可读写 |
| 有界泛型 struct（bounded generic struct） | `struct Box<T: Show> { … }` | 类型参数带一个 trait 约束；实例在创建它的单元校验（`use` / `impl` / 模板 tag 上的 `impl` 都算满足），impl 方法体按位置继承该约束并静态派发，不加 vptr（Phase 33，见 [language-spec](language-spec.md) §4.54） |
| 嵌套 impl pattern（nested impl pattern） | `impl<T> Box<Box<T>> { … }`、`impl<T> Pair<T, Box<T>> { … }` | 按结构递归匹配、自内向外绑定；pattern 里的裸类型参数不登记伪实例；depth = `Box` 个数 − 1，>4 报 L33-4，不支持的形态报 L33-5（Phase 33） |
| 跨单元元素副本（cross-unit static copy） | 消费方 `.c` 里的 `static <instance>_<method>` | 元素 owner ≠ 容器模板 owner 时，由创建实例的单元发射私有的元素 helper 与实例方法副本；`.h` 只留类型，vtable / 实例数据留在 owner 单元（Phase 33 / T31-2） |
| `pub` 泛型函数（pub generic function） | `pub T f<T>(T x)` | 模板体须写在 `.h.ct`；消费方每个 `(f, 实参)` 在本单元发一个 `static <f>__ct<N>`，`.h` 只放类型（Phase 34；L26-2 已解禁） |
| 非泛型固有方法（non-generic inherent method） | `impl Counter { int get() { … } }` | 非泛型 struct 的固有 impl；落码 `<Struct>_<method>`，属主单元定义一次、消费方从 `.h` 取原型（Phase 34） |
| `Option` / `Result` | `Option<T>`（`has` + `value`）、`Result<T, E>`（`ok` + `value` + `err`） | `lib/std` 的普通泛型 struct，带 `use Drop`；字面量构造，`unwrap` 在错侧 `abort`，`release` 是 no-op；`none()` / `ok()` / `err()` 零初始化未用 payload 使无条件胶水安全释放；`?` / pattern / 自动释放属后续阶段（Phase 34 / Phase 36） |
| 泛型 trait（generic trait） | `trait Iter<T> { T next(void); }` | 按实参单态化为实例行（`Iter<int>` → `Iter_int`），产物 `<Trait>_<ct_inst_encode 输出>_*`（`Iter_int_vtbl` / `__iter_int_vptr` / `Circle_Iter_int_next`，嵌套实参按转义、≥64 字符走哈希回退）；实例只能在模板属主单元创建（跨单元 L35-4），不支持默认方法体（Phase 35，见 [language-spec](language-spec.md) §4.55） |
| 长度前缀字符串 Str | `struct Str { char *data; int len; }`（`lib/std/Str.h.ct`） | 内建句柄，`len` 是契约（保留内嵌 `\0`）；`str_from` / `str_from_len` / `str_len` / `str_slice` / `str_concat` / `str_compare` / `str_c_str`；方法 `retain()` 深拷贝、`release()` 释放并置 `data=0,len=-1`；`impl Drop for Str` 释放 buffer；按值传递浅拷贝指针，需显式 `retain()` 深拷贝（Phase 36，见 [language-spec](language-spec.md) §4.56） |
| 析构胶水（drop glue） | 编译器生成的 `<S>_Drop_drop` | 无显式 `impl Drop` 时按字段声明顺序递归释放每个 `uses_drop` 字段；写了显式 `impl Drop`（含 `impl<T> Drop for Box<T>`）即自负全责、不再生成字段胶水；泛型 Drop 每实例单态化一份、不产生模板态（Phase 36） |

### 2. 命名 / 修饰规则（已发布契约）

| 术语 | 代码形式 | 说明 |
| --- | --- | --- |
| 命名修饰（mangling） | `A::B::S` → `A_B_S` | 空/顶层命名空间**不加**前缀 |
| 修饰后的 C 名（cname） | `Trait.cname` / `Struct.cname` | 源码里的规范 C 符号名 |
| 虚表类型 | `<Trait>_vtbl` | |
| 接口值类型 | `<Trait>_iface` | |
| vptr 字段 | `__<trait>_vptr` | trait 名小写；字段名在 struct 内，**不加**命名空间前缀 |
| 方法函数 | `<Struct>_<Trait>_<method>` | |
| vtable 变量 | `<Struct>_<Trait>_vtable` | |
| 文件作用域构造器 | `__ct_init` | `static void __ct_init(void) __attribute__((constructor))`：在 `main` 前为文件作用域对象 / 数组写 vptr（D5=A） |
| 导出虚表（exported vtable） | `extern struct <T>_vtbl <S>_<T>_vtable;` | `pub trait` × `pub struct` 时 vtable 去掉 `static`，实现单元定义、头文件声明，消费单元可直接装箱；否则保持 `static`（单元私有） |
| 实例级虚表（instance-level vtable） | `<实例 C 名>_<Trait>_vtable` | `map` 的虚表；实例是 `pub` 全局且 trait 为 `pub` 时同样导出 |
| 全局 C 名（global cname） | `namespace A::B; int h;` → `A_B_h` | 命名空间内全局按前缀 mangling；`extern` 豁免（保持 C 库原名） |
| 单元命名（unit naming） | 文件 `Parser.h.ct` ↔ `struct Parser` | 每个单元以主类型命名，一个单元一个主类型，附属记录类型可同文件；主类型过大可拆**子对象单元**（文件头注明所属主对象）；入口 `main.ct` 例外；`check-ast.sh` 的 unit-name lint 校验 |

> 以上是**已发布命名规则**，除非用户明确要求，不得更改（AGENTS §2）。

### 3. 编译器实现

| 术语 | 代码形式 | 说明 |
| --- | --- | --- |
| 源到源编译器（source-to-source compiler） | `ctc.c` | 输入 `.ct`，输出纯 C |
| 单文件模式 | `ct compile` / `ctc <file>` | `.c` 自包含；Phase 0 行为 |
| 多文件模式 | `ct build <a.ct> … [-o <exe>]` | `.c` `#include` 自己的 `.h`；默认发 C 后调用本地 C 编译器产出可执行文件，`--emit-c` 只发 `.c`/`.h`。**已随 Phase 0.3 移出 L0，现由自举编译器 `selfhost/` 用 CT 重做** |
| 透传（pass-through） | 非构造行原样输出 | |
| 行重写（line rewriting） | `transform_line` 等 | 按行进行；构造与语句同行不重写 |
| 诊断退出 `die()` | `die(pos, fmt, …)` | 唯一错误出口：`file:line:col: error:` 后 `exit(1)` |
| 诊断格式 | `file:line:col: error: message` | 描述小写、无句号、标识符单引号 |
| 字符串缓冲（Buf） | `buf_init` / `buf_puts` / `buf_putc` / `buf_putn` | 不要用 `strcat` |
| 内存分配 | `xmalloc` / `xstrndup` | 失败即 `exit(1)` |
| 容量上限（capacity limit） | `MAX_*` 常量（文件头部） | 越界一律 `die`，**不静默截断** |
| 函数分区（partition） | 工具→源扫描→符号表→签名解析→生成器→构造解析→行重写→`main` | 新增函数放入对应分区 |
| 惰性生成（lazy generation） | drop 函数体 | 仅在被 `delete` 触达时生成，零开销。**已随 Phase 0.3 移出 L0；现由自举编译器 `selfhost/` 用 CT 重做** |
| 传递闭包（drop closure） | `mark_drop_closure()` | 被删除类型递归拉入其 Drop 值字段。**同上，已移出 L0** |
| 生成物 banner | 生成物首部 | 溯源注释 + **输出例外**声明，不得删除 |
| 自包含（self-contained） | 单文件 `.c` | 不 `#include` 生成的 `.h` |
| 头文件守卫（include guard） | `.h` 的 `#ifndef` … `#endif` | |
| 编译单元（unit） | 一个 `.ct` → `.c`（`.h.ct` → `.c` + `.h`） | `ct build` 中每单元只编一次；只有 `.h.ct` 发布接口、可被 `import`。**已随 Phase 0.3 移出 L0；现由自举编译器 `selfhost/` 用 CT 重做** |
| 依赖顺序（dependency order） | 拓扑序 | import 的 DAG 拓扑排序。**同上，已移出 L0** |
| 驱动（driver） | `compile_range` / `compile_file` / `compile_main` | 编排，不碰解析/生成逻辑；L0 现在只做单文件 |
| `#line` 映射 | `#line <源行> "<.ct>"` | 多文件默认开、单文件默认关（D4=A）。**已随 Phase 0.3 移出 L0；现由自举编译器 `selfhost/` 用 CT 重做** |
| 行号发射 | `line_of` / `line_at` / `line_break` | 偏移→行号缓存 / 发射 / 生成块边界强制重发。**同上，已移出 L0** |
| 泄漏警告（leak warning） | `potential_leak` · `leak_check_scope` · `leak_check_return` | 保守：作用域结束仍 owned 报确定泄漏（kind 0）；条件 `return` 留下的未返回对象另报一次 `may leak on a return path`（kind 2，JSON 带 `path_line`）；Phase 6.2 起 `T *q = f();` 若 `f` 可能返回它自己的分配（`ret_owned`），`q` 也计为 owned。**已由 Phase 4/5/6 在 `selfhost/l2/**` 实现** |
| owned（堆对象持有） | `Var.owned` / `own_line` / `autodrop` | 由 `T *p = malloc/calloc(...)` 在创建点标记；Phase 6.2 起 `T *q = f()`（`f` 的 `ret_owned` 为真且返回同一 struct 指针）也标记；`own` 另置 `autodrop`（Phase 5）。**在 `selfhost/l2/**` 实现** |
| 错误恢复（error recovery） | `setjmp` 守卫 + `recover_pos` | `die` 报告后长跳到 `compile_range` 的守卫，并重同步到下一个 `}` 之后或下一行行首；上限 `MAX_ERRORS=20`，失败的编译删除产物并在末尾补 `ctc: N error(s) generated`。Phase 4 切片 3 **新增**（无 oracle） |
| 语义诊断（semantic check） | `duplicate trait/struct` · `signature_mismatch` | 重复定义按 cname 报错（namespace 隔离）；impl 的返回类型 / 参数个数与 trait 不符时告警（**不比参数类型**）。Phase 4 切片 4 **新增**（无 oracle） |
| 前端 / 后端（frontend / backend） | `selfhost/ct-ast/frontend/**` · `backend/**` | 前端：词法 → 解析 → 符号表 → 类型检查 → 模块；后端：发射（`.c` / `.h` / JSON / vptr 初始化） |
| 抽象语法树（AST） | `arena` 里的节点链 | ct-ast 的中间表示；节点种类见 `N_*`（`N_FUNC` / `N_IMPL` / `N_MAP` / `N_GLOBAL` …） |
| 节点（node） | `struct Node`、`self->arena->nodes[n]` | 一条 AST 记录：`kind` + 最多 4 个子节点 + 4 段文本 + `aux` + `d`（`pub` 标志） |
| 节点池（arena） | `runtime::arena::Arena` | 一次性分配的节点与字符串池；不回收，随编译结束释放 |
| 分组多单元（grouped multi-unit） | `selfhost/ct-ast/{frontend,backend,tool}/**` | ct-ast 的源码组织：按全路径 `import`，构建需 `-I selfhost/ct-ast`；宏不跨翻译单元 |
| 行管线（line pipeline） | L2 的 `Pipe` / `RewriteOps` | 旧路线：逐行扫描 + 行重写；ct-ast 已改为 AST 路线，L2 仅作回归 oracle |

### 9. 易混淆术语对照（先查这里）

| 容易混的两项 | 区分 |
| --- | --- |
| trait ↔ iface | trait 是语言构造（契约，可带默认体）；`<T>_iface` 是它在 C 里的**值表示**——胖指针 `{ void *self; <T>_vtbl *vt; }` |
| vtable ↔ vptr | vtable 是函数指针**表**（每 (struct, trait) 一份）；vptr 是 struct **内部字段**，指向该表（`__<trait>_vptr`） |
| impl ↔ map | impl 为**自有 struct** 提供实现，虚表名 `<S>_<T>_vtable`；map 给**已声明的实例**绑定外部函数，虚表名 `<实例C名>_<T>_vtable` |
| `use` ↔ `impl` | `use` 只声明"采纳"（决定 vptr 字段、是否可装箱）；`impl` 提供方法体。trait 全 default 时只写 `use` 即可 |
| 抽象方法 ↔ 默认方法 | 抽象方法必须实现；默认方法可继承、可在 impl 里覆盖 |
| 装箱 ↔ 派发 | 装箱是 struct → iface 的转换（写 `{ &obj, &vtable }`）；派发是转换之后经 vtable 调方法 |
| compile 模式 ↔ build 模式 | 单文件、`.c` 自包含；多单元、每单元出 `.c` + `.h`，`.c` 里 `#include` 自己的头 |
| 单元（unit） ↔ 翻译单元（TU） | CT 的 unit = 一个 `.ct`；C 的 TU = 一个 `.c` 连同它的 `#include` |
| 包装函数 ↔ 直接绑定 | 前者多一层转发（`-> f(args)`）；后者 vtable 槽直接指向 C 函数（`-> f;`），零生成 |
| mangling ↔ cname | mangling 是**规则**（加 `A_B_` 前缀）；cname 是**结果**（`A_B_S`） |
| 正例 ↔ 负例 | 正例必须成功且输出匹配；负例必须非零退出且诊断匹配 |
| golden ↔ oracle | golden 是具体期望产物；oracle 是产出这些期望的**参照实现**（L0 / L2 / `overreach-oracle` tag） |
| 关卡 ↔ 测试层 | 关卡是 `check-all.sh` 的 11 个条目（整体判据）；层是 `test/run.sh` 内部的分组（build / unit / cases …） |
| Phase ↔ Batch | Phase 与版本一一对应（`v0.n.x`）；Batch 是可独立收口的工作单元，Phase 结束后仍可继续累加 |
| 生成物 ↔ 源码 | 生成物（artefact）指 `ct` 输出的 `.c` / `.h` / JSON；banner 与输出例外声明必须保留 |
| 透传 ↔ 行重写 | 透传：非构造行原样输出；行重写：构造行被替换为等价的 C |
| 命名空间路径 ↔ 限定引用 | `A::B` 是**写法**；"限定引用"是按该写法跨命名空间取符号的**行为** |
| 导出（`pub`） ↔ 私有（`static`） | `pub` 的符号进 `.h`；`static` 只留在本 `.c` |
| 借用视图 ↔ 拥有句柄 | 借用（`get` / `entry` / `foreach item`）指向容器存储，不能 `release`，容器变更后失效；拥有句柄来自 `retain` / `pop` / `from` / 花括号初值 |
| 容器句柄 ↔ `ct_buf` 头 | 句柄只有一个 `h` 指针（H-A）；`refs` / `len` / `cap` / `data` 都在共享头里，扩容不会让兄弟句柄悬空 |
| 下标 ↔ 写入 | `v[i]` / `m[k]` 是只读糖（等价 `get`）；赋值、复合赋值、自增、取址都是硬错，写用 `set` / `put` |

### 10. 协作与流程术语

| 术语 | 形式 | 说明 |
| --- | --- | --- |
| issue 编号 | `SH-` selfhost · `DOC-` 文档 · `TEST-` 测试 · `CI-` 门禁 | 编号用于索引与条目标题，**文件名不带前缀**（如 `ct-ast-pub-global-dropped.md`）；文件放 `issues/<模块>/` |
| 严重度 | `High` / `Medium` / `Low` / `Info` | High 指对外失真或影响正确性认知；Info 是设计观察 |
| 设计决策编号 | `D-1` … `D-n` | 每批次一组，**全局不重复**；决策正文写在对应设计记录（`docs/design/**` 为当前阶段，`docs/history/design/**` 为已关闭阶段） |
| 出口条件（exit） | 关卡全绿 + 用例覆盖 + 文档对称 | 缺一不算收口 |
| 收口（close） | 打 tag、勾完 checklist、更新 roadmap | tag 名与 `CTC_VERSION` 必须一致（未 bump 的里程碑用非版本 tag） |
| 验收命令 | `bash selfhost/check-all.sh` | 唯一判定"能不能合"的命令 |
