# 研判记录 · 容器下标可写与嵌套链提案

- 日期：2026-11-15
- 对象：[ct-writable-subscript-proposal](../proposals/ct-writable-subscript-proposal.md)
- 证据基线：HEAD `v0.53.1` 重建 `ct-ast`（`/tmp/cthead`）
- 形式：逐条反证（主张 → 反证 → 裁定）
- 结论：**通过方向**，作为 **PH-62** 立项；吸收 PH-61，不单独先发；本轮不排 phase 卡、不改 `selfhost/**`

## 1 主张席

- JSON 写回需要 `doc["server"]["host"] = "..."`，今天两条路都断：单层写被拒、嵌套链发坏 C；
- `Map::get` 返回 `V*`、`Vec::at` 返回 `T*`，已有足够底层能力，缺的是赋值路径与物化；
- 可写下标与 PH-61 的追加同属一个语法族，应合并，避免两次改同一处。

## 2 反证席

| # | 反证 | 裁定 |
| --- | --- | --- |
| C1 | 用 `m.put(k,v)` / `v.set(i,x)` 就够了，不必加语法 | 部分成立，但 `doc["server"]["host"] = ...` 无法表达；嵌套物化才是主诉求。保留方法式作为底层，不替代语法。 |
| C2 | 把 `m[k]` 改成真 lvalue（读类型 `V`）更自然 | 否决。会破坏 `*m["a"]`、`m["a"] == 0`、`get -> V*` 的既有契约；只做「赋值形态」，读类型不变。 |
| C3 | `v[i] = x` 越界沿用 `set` 的 no-op 最省事 | 否决。正是负责人要求正面解决的问题；静默不写不可接受。 |
| C4 | 越界自动扩展更符合「写到哪都能写」 | 否决。掩盖下标 bug、可放大内存、与 `push` 语义冲突；选硬错 + 常量折叠。 |
| C5 | 嵌套读缺键应该 abort | 部分成立，但单层 `m["k"]` 已返回 0；链上 abort 会制造不一致。选零值传播（R1）。 |
| C6 | 嵌套写缺中间层也应该 abort，让用户显式建 | 可行但不符合 JSON 写回；选只对 Map 中间层自动创建（W1），Vec 仍 abort。 |
| C7 | 自动创建中间 Map 会泄漏 | 成立，列为**实施前置**：临时句柄必须 release，并有 ASan/引用计数夹具；否则提案不通过。 |
| C8 | 嵌套写照抄 C 下标链即可 | 否决。实测 `m["a"][0] = 1` 生成 `Map_get(...)[0]`，cc 报「assigning to 'struct Vec_int' from int」；必须 Map 步取指针、Vec 步用 `at`。 |
| C9 | `?[` 已经能读，为什么还要朴素链 | `?[` 不能写（实测 `optional chain/subscript is not an lvalue`）；朴素链是读写都需要的形态，`?[` 保持只读。 |
| C10 | 先发 PH-61 再发可写下标 | 否决。PH-61 明文「不放开 `v[i] = x`」，与本需求冲突；先发会产生返工和自相矛盾的中间态。吸收为 PH-62 的 S1。 |
| C11 | 会动 ABI | 不成立。降级为 `get/put/set/at`，辅助函数只进生成的 `.c`（static），不改 `.h` / `.abi.h`。 |
| C12 | 既有合法程序会改义 | 不成立。`m[k]=v`、`v[i]=x` 今天都是硬错；`m[k]` 读类型不变；嵌套读今天本来就编译失败。 |

## 3 裁定

- **定性**：新能力（B）；嵌套朴素读的「静默坏 C」是 A 类子项，可先止血，但完整能力走 PH-62。
- **通过条件**：
  1. 只做语句级赋值，读类型不变（`Map -> V*`、`Vec -> T`）；
  2. `Vec` 越界硬错 + 常量折叠，不自动扩展；
  3. 嵌套读零值传播，嵌套写只对 Map 中间层自动创建；
  4. 物化必须用 `Map_get` 指针 + `Vec_at` 指针；自动创建句柄必须 release；
  5. 吸收 PH-61，废止其「不放开 `v[i] = x`」非目标。
- **落点**：**PH-62**；PH-61 作为 S1 切片，不再单独占号；本轮不排 phase 卡。
- **建议切片**：S0 读物化/诊断位置 → S1 `v[]=x` → S2 单层写/越界 → S3 嵌套读 →
  S4 嵌套写/自动创建 → S5 所有权与 golden。

## 4 未决问题

1. 运行时越界 abort 的文案与错误码；
2. `Vec` 中间层是否允许自动扩展（裁定：不允许，保持 A1）；
3. `v[i] = x` 的常量折叠是否要求 `len` 可在编译期求得；
4. 是否顺手修 `1:-3788` 负行号诊断（建议单独 patch，不夹带）；
5. 嵌套写是否覆盖 `Vec` 元素 struct 的字段写（`v[i].f = x`；建议后续单列）。

## 5 留档声明

- 本记录只做研判，不含实现承诺；
- 提案阶段不改 `selfhost/**`、不排 phase 卡；
- 在需求定稿前，本能力不进入 patch 队列；嵌套读的止血补丁可单独评估。
