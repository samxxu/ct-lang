## 2 判据两级制（A1）

| 层 | 对象 | 判据 |
| --- | --- | --- |
| 第 1 层 | **测试语料**（`test/cases/**`、`test/ast/*/prog.ct` 等）的发射产物 | 逐字节不变；这是“不改发射格式/命名契约”的落点 |
| 第 2 层 | **编译器自身实现**（`selfhost/ct-ast/**`）的发射 C | 允许差异（switch→match、`?`/errdefer 改造的必然结果）；验收 = 自举不动点 + ASan + 行为测试 |

两层禁止混用：不得用第 2 层的差异去解释第 1 层回归，也不得要求编译器自身产物逐字节冻结。

## 3 golden 集合基线（A2）

- 每个命令（`ct build --emit-c`、`--lib`、自举段）维护一份**期望文件集合基线**；
- M0/M1 可以有意图地改变集合（拆分/改名），但必须：
  1. 同一 commit 更新基线；
  2. 附“旧文件 → 新文件”映射；
  3. 旧集合中的每个语义单元在新集合中仍有对应；
- 集合比对实现 = 扩展自举不动点段的遍历层（不是新工具），成本按 M0 卡估算（约 2–3 人日）。

## 4 M0 / M1 判据（A3/A4/A5）

- **J1**：函数体哈希集合不变 + 机械行白名单（import/include/声明重排）；`git diff -M` 只作辅助证据；
- **J4**：M 不新增 import 环；现状环清单先交，破环单独成案，不算纯搬移；
- **A5**：4K 行阈值先按函数分布校准；校准前写入“每子系统单元数不设上限、阈值仅告警”作为 M0 卡判据。

## 5 状态与命名（B1/B2）

- M 的前置交付物：文件级状态清单（`g_sb`、`g_slice_used`、`g_emit` 等）与归属规则；
- 规则：状态随主要使用方走；跨单元访问走 `pub` 接口或显式传参；允许 `static→pub` 的接口变化，但不得改行为；
- 命名：`<Subsystem><Role>.h.ct`（PascalCase，全局唯一），如 `LexerTokens.h.ct`；
- `--emit-c` 产物名、ABI 头、下游脚本的影响列入 M0 卡发布前检查。

## 6 事实修正（B3/B4）

- ct-ast **函数与全局可先用后定义**（自动补原型）；类型/trait 必须先声明；
- token 采用源缓冲 `Str` 视图：源缓冲生命周期覆盖整个解析阶段；NUL 相关 C API 系统迁移为带长比较与 `cstr()`；
- 以上写入词法器 R 卡（PH-86），M0/M1 不碰语义。

## 7 时序（C1/C3/C4）

```text
PH-84  ADT/match
PH-85  inventory + 单切片 spike（门） + M0 粗切（5–6 单元） + A 机制接线
PH-86  词法器 R
PH-87  解析器 + 检查器 R
PH-88  发射器 R + 自举不动点
v1.0   AST-only 收口（不被 M 阻塞）
v1.1   S1 M1 精细切分（纯移动） → S2 A 默认强制
```

- M0 是 R 的 diff 可读性前置；M1 是 v1.1 的组织收尾，不影响 v1.0 发布；
- M0/M1 期间单写者分支；合入窗口要求 `check-all` 全绿；
- D6 冻结窗口仍为 PH-85–88（M0 在内）；v1.1 的 M1 不扩 D6。

## 8 失效条件

- 若要求 R 也移到 v1.1，需显式覆盖 D1 与本文件第 1 条；
- 若要求 M1 成为 v1.0 门禁，需显式覆盖第 7 条并延长 D6；
- 若集合比对证明无法在自举段内实现，需另立工具提案并重估成本。
