## 背景

用户提交《指针退场——`box` 句柄 / `new` 表达式 / 切片 / `ref`·`out` / `Str` 一等化》，
希望把堆单对象、多返回、数组传递、字符串、回调五类日常用途收进句柄/值类型。
提案基线 v0.77.0；battle 在 v0.77.1 上评审。

## 1 battle 原判（历史）

battle 判 B：整体方案不进 v1，退回 v2/REQ，先补 P-1…P-5。
该判决的事实基础是 v1.0 语言冻结与 v1.1 行为保持；证据门槛未过。

## 3 裁定

1. **接受方向**：以 T1（`String`/`Str`）、C1（`T[]` 唯一）、四位置白名单、四机制家族为后续 v0.x phase 的设计基线；
2. **v1.0 不顺带扩围**：语言特性走 v0.x phase；v1.0 仍是 AST-only 收口，只是发布顺延；不改「v1.0 语言冻结」的口径；
3. **证据门槛仍是硬门**：J-6/J-7/J-8 未过前不开施工卡；P-1…P-7 见
   [提案 v2 附录 A](../proposals/pointer-free-v2.md#附录-a--证据任务清单)；
4. **不采纳**：J1「与指针写法产物逐字节一致」作为 box/Str/slice 的通用判据；「只新增一个关键字」的表述；在没有逃逸限制时把 `ref/out` 当日常默认；无迁移的 `T[]` 重定义；把 debug 泄漏计数叫「环检测」；
5. **不变**：指针/own/defer/errdefer 继续合法；`c-boundary` 只圈 C 边界，不圈指针类型；`T a[]` 废弃是迁移规则，不是新机制。

## 4 理由（复核后仍成立的硬事实）

- `Str` 是 std 包类型（[Str.h.ct:18](../../lib/std/Str.h.ct#L18)），字面量默认化必须解决内建化与 ABI；
- `Str.slice` 当前是深拷贝（[Str.h.ct:68-77](../../lib/std/Str.h.ct#L68-L77)），不是借用视图；切片引入新风险；
- `ref`/`out` 已是合法标识符，`T a[]` 已是现有语法（[prog.ct:3](../../test/ast/132_foreach_array_values/prog.ct#L3)）；
- 无借用检查/环检测/逃逸限制时，box/ref 会把泄漏与悬挂隐式化；
- 提案尚无原型与实测证据，J-6 不能跳过。

### 6.1 2026-11-20 追加裁定（字符串与下标）

详见[提案 v2 附录 C](../proposals/pointer-free-v2.md#附录-c--2026-11-20-追加裁定字符串与下标)：

- `String` 字面量用 L1 immortal 静态句柄；`String s = "x"` 与 `Str v = "x"` 都合法；
  `U16String` 只走工厂，不新增字面量前缀；
- `T a[] = {...}` 恢复为推断长度数组；`T[]` 是切片；`T a[]` 仅无初始化器/形参时废弃；
- C 数组保持 C 下标；切片 `s[i]` 是带边界检查的 place，越界 trap，`get` 软访问；
  `const T[]` 只读，`String`/`U16String` 永远不可写；
- 双编码：`String`/`Str` UTF-8，`U16String`/`U16Str` UTF-16；跨编码只走工厂；
- UTF-8 用户接口用码点下标，字节级走 `byte_*`；`String[i]` 只读单码点 `Str`；
  `U16String[i]` 只读单 code unit `U16Str`；
- `String` 按 JS 不可变值语义；内容变化返回新 `String`，`Str` 能零拷贝则返回视图；
- `U16String` 首轮只做 JS 核心子集；`match`/`locale_compare`/`normalize` 等走
  `ct-pkg` 包 + `.m.ct`/shim，不把正则/Unicode 表塞进编译器；
- `box` 环与跨线程共享无法编译期保证；只做直接形态 lint + 作者责任，不加第七项机制。
