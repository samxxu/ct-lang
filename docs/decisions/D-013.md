## 2 `.data` 类型（P-7.4-1）

- `.data` 的静态类型为 **`const char *`**（UTF-8）/ `const u16 *`（U16），**只读、不保证 NUL**；
- 不提供到 `char *` 的隐式转换；`printf("%s", s.data)` 在 `ct check --types` / `ct build` 硬错（或 lint，二选一由 S5a-1 红证固定）；
- `cstr()` 是 C 边界唯一出口，负责补 NUL（必要时复制）；
- 负例必须包含 `printf("%s", s.data)` 与子视图 `.data` 无 NUL 两类。

## 3 复制/retain 合同（C-6）

采用**自动 retain**（提案 Q5）：

- 按值传参、按值返回、字段赋值、容器插入 `String` 时，按静态类型 retain；
- 局部句柄 `return` = move；非局部 owning `return` = retain→return→release；
- 重新赋值：先 retain 右值，再 release 旧值；
- refcount 普通 `int`、非原子、非线程安全；作者负责同步；
- `refs = -1` 为 immortal（字面量/空串），release 首行直接返回。
