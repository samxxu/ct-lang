## 8 新反例（归档自举，3 条）

- **CE-1 `emit_node` fall-through（N_DECL）语义。** 在临时副本把
  `if (r != 2) return r;` 改成 `return 0;`，重编 ct-ast。普通声明
  `int x = 1; return x - 1;`：HEAD 生成 `int x = 1;`、编译运行 rc=0；变异体
  **ct-ast rc=0 但静默丢掉声明**，生成的 C `cc` 报
  `use of undeclared identifier 'x'`。证明三态返回是语义必需，而非等价改写。
- **CE-2 容量边界（>1024）。** 1024 个 distinct callee 通过，1025 个失败，消息
  逐字 `too many distinct calls`（§2）；v0.87.0 的 512/513 同一消息。把 HEAD
  源码 cap 改回 512 后自编译在 `Pkg.h.ct:1650` 以同一消息失败，HEAD 正常。
- **CE-3 全夹具差分。** 363 个夹具的退出码/stdout/stderr/发射 C 在 v0.87.0 与
  v0.88.0 间 0 mismatch（§4），覆盖 66 语料之外的大量 kind。
