| 项 | 值 |
| --- | --- |
| 评估对象 | 外部提案《v1.0 收口战役——自举去级 / 编译器现代语法重写 / 发布前清单》（2026-11-21 收，仓外文件） |

## 1. 提案摘要

- §3 自举去级：J-6 后拆 L1/L2、先做 goldens 静态化、保留 L0 种子；
- §4 把 ct-ast 用新语法重写，并提前到 v1.0 之前；
- §2 发布前清单 G1–G10；
- §5 顺序：golden 静态化 → 去级 → ADT（可选）→ 四切片重写 → 三轮自举 → v1.0。

## 6. 风险提示

| 风险 | 说明 |
| --- | --- |
| 重写提前 | 把 MAJOR 收口从“删旧管线”扩大为“42.8k 行重写”，失败隔离与版本纪律变差 |
| 零拷贝词法器 | `Str` 非 NUL 结尾，现有 `strcmp`/`%s` 用法需系统性改造，不是纯语法替换 |
| 函子依赖 | S4 未落地；在重写中引入会同时改变两件事的失败归因 |
| 并发开发 | 多会话并行提交；“不冻结 + rebase”会放大冲突成本 |
| deadline | 与“不承诺时间”口径冲突，且 J-6 证据量未知 |
